Research

Power and thermal

Power delivery and thermal management in 3D stacked systems

PDN efficiency · IR drop · peak temperature · 3D stacked HBM

Stacking memory above compute puts the power delivery path and the heat removal path in competition for the same vertical resources. I studied 3D stacked HBM with compute accelerators for LLMs, quantifying delivery efficiency and IR drop through the substrate, interposer, and vias alongside the peak temperature the stack reaches, and identifying the configurations where both stay within limits. Related work with collaborators examines voltage regulators embedded directly into a glass substrate, which moves the regulation stage closer to the load.

IEEE JXCDC, vol. 11, pp. 116–122, 2025; ECTC 2026.

Packaging co-optimization

System-technology co-optimization across packaging schemes

2.5D / 3D integration · design-space exploration · STCO

How an accelerator is partitioned across dies fixes the bandwidth, parasitics, and area available to it, so the packaging scheme cannot sensibly be chosen after the architecture. This methodology evaluates 2.5D and 3D options, propagates the resulting package-level quantities into system power, performance, and area, and pairs the model with an optimizer that returns the best dataflow for a given architecture and set of hardware constraints. Applied to Llama 2-13B across several package configurations.

IEEE JETCAS, vol. 15, no. 4, pp. 577–584, 2025. Extended during an internship at Intel.

Memory and datapath

Evaluating 3D stacked DRAM for transformer inference

3D stackable DRAM · heterogeneous integration · MoE serving

Transformer inference is usually limited by memory bandwidth rather than arithmetic, which makes the placement of memory a system-level question rather than a component choice. I modeled accelerators with 3D stackable and capacitorless DRAM integrated over the logic die and compared them against off-package alternatives on energy, area, and achievable throughput. The same modeling supported collaborative work on mixture-of-experts serving, where expert loading from DRAM dominates both energy and bandwidth.

AICAS 2024; IEEE Nanotechnology Magazine, vol. 19, no. 2, 2025; MICRO 2025; IEEE JXCDC, accepted.

Optical interconnect

Assessing co-packaged optics at cluster scale

co-packaged optics · escape routing · cluster modeling

Electrical interconnects limit reach and energy per bit as accelerator counts grow, and moving the optical engine into the package addresses both at the cost of additional escape routing and thermal coupling. I extended the accelerator model to a large-scale cluster with co-packaged optical interconnects and evaluated whether the configuration holds up for training a one-trillion-parameter model, accounting for those package-level costs rather than assuming an ideal link.

IEEE T-CPMT, vol. 15, no. 11, pp. 2282–2289, 2025.

Thermal analysis

Thermally constrained operating points for heterogeneous 3D systems

finite-element analysis · compute-in-memory · RISC-V · mixed workloads

Power dissipated anywhere in a stack leaves through a single thermal path, so peak temperature bounds what the rest of the design can do. I modeled complete stacks in ANSYS Mechanical to extract peak temperature, and contributed to a framework that selects per-block operating points and air-cooling configuration for a heterogeneous accelerator of compute-in-memory macros, a digital ML accelerator, and RISC-V cores, optimizing power and latency subject to a temperature limit under mixed ML and non-ML workloads.

IEEE T-VLSI, vol. 32, no. 9, pp. 1718–1725, 2024.

Design automation

Encoding electrical constraints into placement

CAD automation · constraint-driven placement

Packages at this scale carry several hundred components whose positions are constrained by power delivery, signal integrity, and assembly rules. I developed a CAD tool that places them automatically, applying the electrical and packaging requirements specific to each module during placement instead of checking them afterwards, which reduces the number of manual design iterations and improves the resulting design metrics.

Developed during a package design internship at Apple.

Near-sensor compute

System and thermal analysis of 3D-stacked image sensors

Cu–Cu hybrid bonding · IWO-FET memory · global shutter · QDTrack

Heterogeneous 3D integration of photodiodes with IWO-FET buffer memory and near-pixel compute circuits, using Cu–Cu hybrid bonding to obtain global-shutter operation with temporal frame filtering at the sensor. Companion studies compare 2.5D and 3D integration of the sensor with a sparsity-aware accelerator for ResNet-50-based QDTrack inference, model the package in ANSYS Mechanical to establish the peak temperature each option reaches, and quantify how in-pixel circuit non-idealities propagate into multi-object tracking accuracy.

IEEE TCAS-I, vol. 70, no. 5, 2023; IEEE J-EDS, vol. 12, 2024; EDTM 2023; MWSCAS 2024.
